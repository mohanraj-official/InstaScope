# Instagram Performance Analysis

A Power BI dashboard built to explore Instagram post performance using
data collected through the Instagram API.

![Instagram Performance Dashboard](./dashboard%20image/INSTAGRAM_DASHBOARD.png)

## Dashboard Highlights

-   Views, reach, likes, shares, and saves
-   Performance by media type and year
-   Views by posting time and day
-   Trends in views, reach, and likes
-   Interactive filters for media type, year, and time of day

## Tools Used

Power BI · Power Query · DAX · Instagram API

## Data Workflow

Instagram API → Power Query transformation → Power BI dashboard
